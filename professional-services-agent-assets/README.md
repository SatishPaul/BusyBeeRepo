# Professional Services Agent Assets

Deployable, agent-first solution packs for professional services. Each pack ships a working Dataverse solution, copy-paste prompts (Copilot, Cowork, Scout, Copilot Studio, GitHub Copilot, Dataverse Skills), synthetic sample data, real execution evidence, an ROI model, and a deployment guide. Import and run in your own tenant.

Structure: `tax/ audit-assurance/ advisory/ it-consulting/ shared/ catalog/`.

Every pack applies an agent-first necessity test (Eliminate / Compress / Assist / Orchestrate / Autopilot) and reserves human judgment for exceptions. Apache-2.0. Synthetic data only; figures illustrative until measured; Microsoft Scout is a preview product.
