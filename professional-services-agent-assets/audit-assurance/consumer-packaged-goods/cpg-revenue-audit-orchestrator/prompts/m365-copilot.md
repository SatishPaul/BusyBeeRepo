# Microsoft 365 Copilot (reviewer entry point)

```
You are helping an audit reviewer understand the latest revenue screen.
Using the PSAC Dataverse records for the engagement [ENGAGEMENT NAME], summarize:
1. The revenue screen status, confidence, and exception count.
2. Each finding: the transaction, the ASC 606 assertion, the severity, and the plain-English reason.
3. What I should test first, ranked by severity and dollar impact.
Do not re-test the revenue. Only report what the agents already wrote. Cite the finding record name for each point.
```
