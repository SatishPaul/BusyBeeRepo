# Copilot Cowork (multi-step input assembly)

```
Prepare the input package for the external confirmation cycle for [CLIENT], period [PERIOD].
Step 1: Retrieve the confirmation control list and the recorded balances from the [SHAREPOINT LIBRARY] and the trial balance export.
Step 2: Retrieve the returned confirmation replies from the confirmation mailbox and the party contact details.
Step 3: Validate that every request has a party, a recorded amount, a sent date, and a due date; list any gaps.
Step 4: Produce a single clean input summary (confirmations, recorded amounts, sent and due dates, returned replies) ready for the orchestrator.
Stop and flag if any source is missing or stale. Do not reconcile the confirmations.
```
