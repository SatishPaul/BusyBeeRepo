## What it does

Every audit sends external confirmations, to banks, customers, and lenders, then spends weeks tracking which came back, chasing the ones that did not, and tying each returned confirmation to the recorded balance. It lives in a spreadsheet, it is manual, and a single missed non-response or an unreconciled discrepancy can leave a material balance unsupported. This pack replaces the spreadsheet with a **master orchestrator and five specialist agents** that track every confirmation request, match every response, reconcile confirmed against recorded, age the non-responses, and write plain-English findings to Dataverse. A human judges only the exceptions.

In the bundled Manufacturing scenario (Larkspur Manufacturing, FY26 audit), the agents tracked **40 confirmation requests and auto-flagged 3 exceptions**: a bank balance that came back different from the books, the largest customer's confirmation that never returned, and a lender confirmation returned unsigned and missing a required term.

## The classification: Autopilot

Under the agent-first necessity test, this is an **Autopilot** process. The command center runs continuously through fieldwork, tracks and reconciles every confirmation on its own, and stops only for the exceptions and the human approval gate. It is not a person with a status spreadsheet; it is a process that never loses a confirmation.
