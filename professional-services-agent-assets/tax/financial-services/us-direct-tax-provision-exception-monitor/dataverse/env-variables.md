# Environment Variables

- `psac_ConfidenceThreshold` (decimal, default 90): findings below this are marked for mandatory human review.
- `psac_CostCeilingUsd` (decimal, default 10): a run that would exceed this pauses for approval.
- `psac_DefaultApprover` (string): the role or user notified at the approval gate.
- `enablePrivateNetworking` (bool, default false).
