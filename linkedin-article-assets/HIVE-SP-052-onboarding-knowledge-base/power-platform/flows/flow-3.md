## 3 · Knowledge & Ramp Dashboard · Power BI

#### Context
**Persona:** Practice leadership. **Problem:** leaders cannot see knowledge coverage or ramp impact. **Success criteria:** a dashboard shows question coverage, ramp time, lesson reuse, and knowledge gaps.

#### Data model
Use `proserv_query`, `proserv_lesson`, and `proserv_ramp`.

#### Components
Power BI dataset, scheduled refresh from Dataverse, and drill-through by topic.

#### Build steps
1. Model queries, lessons, and ramp metrics.
2. Show question coverage over time.
3. Track new-hire ramp time.
4. Report lesson reuse.
5. Flag topics with no coverage.

#### Demo script
Leadership sees ramp time fall and coverage rise. **Wow moment:** institutional memory becomes a managed asset.
